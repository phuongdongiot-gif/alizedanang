## 2025-06-15 - Nuxt Nitro JSON Data Imports Optimization
**Learning:** Nuxt's Nitro server natively supports ES module imports of JSON files. This approach caches the parsed data in memory on import, avoiding expensive asynchronous file system reads (`fs.readFile`) and JSON parsing (`JSON.parse`) per request. A crucial caveat is that the imported object acts as a shared singleton; direct mutations will persist across future requests causing difficult-to-debug state bugs. Always use non-mutating methods like `Array.filter()`.
**Action:** When working on Nuxt backends serving static JSON data, prefer direct ES module imports for better performance. Ensure that any operations on the imported data do not mutate the cached instance directly to prevent pollution across user requests.
