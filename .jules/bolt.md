## 2024-05-18 - Nuxt Nitro Static JSON Imports
**Learning:** In Nuxt/Nitro deployments, `fs.readFile` with `process.cwd()` can fail in production because the working directory may not point to the original source directories. Furthermore, reading files dynamically creates overhead per request. Nitro natively supports direct ES module imports of static JSON files (e.g., `import data from '../data.json'`) without import assertions, which are bundled and cached in memory automatically, making them both safer and faster.
**Action:** Use direct static imports for JSON files in Nitro API routes instead of `fs.readFile` and `JSON.parse`. When doing so, remember to treat the imported object as immutable, since it is cached across requests, unlike `JSON.parse` which provided a fresh clone.
