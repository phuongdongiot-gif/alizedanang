## 2024-06-06 - Optimize JSON Loading in Nuxt Nitro with ES Imports
**Learning:** Nuxt's Nitro server natively supports ES module imports of JSON files (e.g., `import data from '../data.json'`) without requiring import assertions. This approach is more bundler-friendly than using dynamic `fs.readFile` with `process.cwd()`, as it automatically caches the data in memory and prevents common production bugs where `process.cwd()` does not point to the original source directories. However, because the imported object is cached in memory, direct mutations will persist across requests; always use non-mutating methods like `.filter()` to safely manipulate this data.
**Action:** When working in Nuxt/Nitro, prefer static ES module imports over `fs.readFile` for static JSON files to ensure memory caching and avoid file path resolution issues in production. Ensure non-mutating operations are used on the imported JSON objects.
