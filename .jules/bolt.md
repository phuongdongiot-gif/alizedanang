## 2024-05-11 - Static JSON Import Optimization
**Learning:** Nuxt's Nitro server optimally handles ES module imports for static JSON files (e.g., `import data from '../data.json'`). By using imports instead of dynamic `fs.readFile` coupled with `JSON.parse` inside request handlers, the JSON is bundled and cached in memory. This drastically reduces the overhead per request, making API endpoints extremely fast and bypassing typical `process.cwd()` path resolution issues in production.
**Action:** When dealing with static data that acts as a mock or simple read-only database in Nuxt/Nitro APIs, immediately prefer direct ES module imports over dynamic file system reading. However, ensure that any data filtering operations return new objects/arrays to avoid mutating the in-memory cached state across concurrent requests.
