## 2024-06-28 - Optimizing JSON Reads in Nuxt Nitro
**Learning:** In Nuxt Nitro applications, using `fs.readFile` coupled with `process.cwd()` to parse local JSON files on every request introduces a serious performance bottleneck due to excessive disk I/O and synchronous parsing. Furthermore, `process.cwd()` is prone to failure in production environments if the deployment directory structure deviates from local development.
**Action:** When a Nuxt API endpoint needs to serve static data from a JSON file, utilize native ES module imports (e.g., `import data from '../data.json'`). Nitro automatically bundles the JSON file, caching the data in memory upon initialization and dramatically reducing response latency while improving deployment reliability. Ensure any subsequent data manipulations (like filtering) use non-mutating methods, as the imported JSON object is cached globally and direct mutations will persist across requests.
