## 2024-10-24 - Optimizing JSON Data Loading in Nuxt Nitro
**Learning:** Nuxt's Nitro server natively supports ES module imports of JSON files. Using direct static JSON imports (e.g., `import data from '../data.json'`) is significantly more performant than using `fs.readFile` coupled with `process.cwd()`, because Nitro automatically bundles and caches the imported JSON data in memory. This avoids inefficient filesystem read operations and `JSON.parse` executions on every request. Furthermore, it is much safer for production environments, as it eliminates common bugs where `process.cwd()` points to unexpected locations after bundling. Be careful to use non-mutating array/object methods on the imported data to prevent cross-request state pollution, since the object is cached in memory.
**Action:** Default to using static ES module imports for JSON files within Nuxt Nitro applications (`server/` directory) rather than dynamic filesystem reads, unless the file content is expected to change dynamically at runtime without a redeploy.
