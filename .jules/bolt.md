## 2025-06-29 - Leverage Nuxt Nitro static JSON imports
**Learning:** Nuxt Nitro natively supports direct ES module imports of static JSON files (`import data from './data.json'`), automatically bundling and caching the data in memory. This is vastly more performant and reliable than manually reading the files on every request using `fs.readFile` and dynamically resolving paths with `process.cwd()`, which is prone to breaking in production deployments if the working directory changes. However, keep in mind that the imported object is a singleton cached in memory, so always use non-mutating methods like `.filter()` if you need to manipulate the data per request, to prevent side-effects.
**Action:** Always prefer direct static imports for JSON data in Nuxt API endpoints to boost performance, reduce I/O overhead, and avoid `process.cwd()` bugs.
