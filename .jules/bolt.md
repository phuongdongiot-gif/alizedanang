## 2024-06-14 - Static JSON Imports vs Dynamic fs.readFile in Nuxt Nitro
**Learning:** In Nuxt Nitro server environments, utilizing direct static ES module JSON imports (e.g., `import data from '../data.json'`) is superior to dynamic `fs.readFile` coupled with `process.cwd()`. Static imports enable automatic bundling and in-memory caching natively supported by the bundler, avoiding inefficient I/O operations per request. Furthermore, they prevent common production bugs associated with `process.cwd()`, which often fails to point to original source directories when deployed in a compiled output structure.
**Action:** Always prefer static ES module JSON imports over dynamic runtime file reads (`fs.readFile`) when retrieving static data files in Nuxt backend API routes to improve performance and deployment reliability.
