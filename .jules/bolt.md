## 2024-08-12 - Optimize static data loading in Nuxt Nitro
**Learning:** In Nuxt/Nitro, using dynamic `fs.readFile` with `process.cwd()` to load static JSON data on each request is an anti-pattern. It causes slow disk I/O, parses JSON unnecessarily on every request, and often breaks in production builds because raw static files aren't bundled automatically. Nitro natively supports ES module imports of JSON files, which automatically bundles the data and caches it in memory as a read-only constant.
**Action:** Always use static ES module imports (e.g., `import data from '../data.json'`) instead of `fs.readFile` for static JSON files in Nuxt Nitro. When the data needs filtering or mutation, assign it to a mutable variable first (e.g., `let items = data`) and use non-mutating methods (like `.filter()`) to prevent altering the cached module.
