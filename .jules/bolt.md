## 2024-05-18 - Replacing fs.readFile with static JSON imports in Nuxt/Nitro
**Learning:** In Nuxt/Nitro deployments, utilizing direct static JSON imports is more bundler-friendly than using dynamic `fs.readFile` with `process.cwd()`, as it prevents common production bugs where `process.cwd()` does not point to the original source directories. Furthermore, Nitro natively supports ES module imports of JSON files, which automatically caches the object in memory and prevents repetitive file system operations on every API request.
**Action:** When working on Nuxt/Nitro APIs, prioritize importing static JSON files over `fs.readFile` + `JSON.parse` unless dynamic reads are strictly required, to benefit from memory caching and better bundler compatibility. Be mindful that mutations to the imported object will be persisted across requests.
