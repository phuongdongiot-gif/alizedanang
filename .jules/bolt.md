## 2024-05-17 - Nitro Data Caching with Static JSON Imports
**Learning:** In Nuxt/Nitro deployments, utilizing direct static JSON imports (e.g., `import data from '../data.json'`) is more bundler-friendly than using dynamic `fs.readFile` with `process.cwd()`. It prevents common production bugs where `process.cwd()` does not point to the original source directories, and additionally caches the parsed JSON object in memory, avoiding costly file reads and JSON parses on every request. However, this cached object is persistent across requests, so mutations to it should be avoided.
**Action:** When serving static JSON data in Nuxt/Nitro server API endpoints, always use direct ES module imports of the JSON files rather than `fs.readFile`. When manipulating this imported data, ensure methods are non-mutating (e.g. `Array.filter()`).
