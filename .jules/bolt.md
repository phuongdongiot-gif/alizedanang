## 2024-05-02 - Nuxt Nitro Server JSON Import Optimization\n**Learning:** Relying on `process.cwd()` to read files in Nuxt 3 server endpoints is problematic in production environments. Replacing `fs.readFile` with a direct ES module `import` (e.g., `import data from "../data/file.json"`) allows Nuxt Nitro to automatically bundle and statically include the JSON file in the server build output. This significantly improves performance by parsing the data exactly once at startup and caching it in memory, while also implicitly preventing deployment path bugs.\n**Action:** When working with Nuxt APIs, prefer direct static imports over runtime `fs.readFile` for static JSON assets to leverage Nitro caching and avoid path resolution issues.
