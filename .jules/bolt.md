## 2024-05-15 - Nuxt Nitro Static JSON Import Optimization
**Learning:** Nuxt's Nitro server natively supports ES module imports of JSON files (e.g., `import data from '../data.json'`) without requiring import assertions. This approach is significantly more bundler-friendly than using `fs.readFile` with `process.cwd()`. Not only does it avoid inefficient file I/O operations by caching the data in memory, but it also prevents common production deployment bugs where `process.cwd()` might not reliably point to the original source directories.
**Action:** Always prefer direct static JSON imports over dynamic file system reads (`fs.readFile`) in Nuxt/Nitro backend endpoints for static datasets. However, when replacing `fs.readFile` with JSON imports, remember that the imported object is cached in memory, so any direct mutations will persist across future requests. Always use non-mutating methods or clone the data (e.g., `[...data]`) when manipulation is required.
