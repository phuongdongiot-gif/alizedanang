## 2024-06-19 - Nuxt Nitro Server Memory Caching with JSON Imports
**Learning:** In Nuxt Nitro applications, using ES module direct imports for static JSON files (e.g., `import data from '../data.json'`) is highly beneficial. It automatically bundles and caches the JSON data in memory at startup, entirely avoiding the overhead of repetitive, blocking I/O operations (`fs.readFile`) on every request. However, because this imported object is a singleton cached in memory, any direct mutations will persist across future requests.
**Action:** When working with static JSON data in Nuxt Nitro endpoints, prefer direct ES module imports over dynamic `fs.readFile` to leverage memory caching. Ensure to always use non-mutating methods (like `Array.filter()`) to safely manipulate the cached data without unintended cross-request side effects.
