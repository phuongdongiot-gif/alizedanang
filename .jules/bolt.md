## 2024-05-24 - Nuxt Nitro Static Data Anti-Pattern
**Learning:** In Nuxt Nitro applications, using `fs.readFile` with `process.cwd()` to read local JSON files on every request is an anti-pattern. It introduces unnecessary disk I/O per request and causes production bugs because static files aren't automatically bundled, and `process.cwd()` paths may not be accurate in production environments.
**Action:** Always use direct ES module imports (e.g., `import data from './data.json'`) to load static JSON files. This approach allows Nitro to automatically bundle and cache the data in memory, eliminating disk I/O overhead and ensuring robust production builds. Be careful to use non-mutating array/object methods when interacting with the imported data, as it is a read-only cached constant.
