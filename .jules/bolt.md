## 2025-02-23 - Nuxt Nitro File System Read Anti-Pattern
**Learning:** Found a performance bottleneck where backend APIs were using `fs.readFile` and `JSON.parse` with `process.cwd()` to load static JSON files on every request. This not only incurs unnecessary disk I/O and CPU parsing overhead per request but also poses a risk in serverless/production environments where `process.cwd()` might not reliably point to the source files.
**Action:** Replaced dynamic file system reads with direct ES module JSON imports. Nitro automatically bundles and caches the imported JSON data in memory at startup, providing a significant performance boost and safer production deployments. Ensured to use non-mutating array methods (like `.filter()`) because the imported object is globally cached across requests.
