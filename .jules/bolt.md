## 2026-06-11 - Optimize Nuxt Nitro JSON Imports
**Learning:** In Nuxt/Nitro deployments, utilizing direct static JSON imports is more bundler-friendly than using dynamic fs.readFile with process.cwd(), as it prevents common production bugs where process.cwd() does not point to the original source directories. Furthermore, direct JSON imports are cached in memory. Any direct mutations to the imported object will persist across future requests, unlike JSON.parse which provides a fresh clone per request. Always use non-mutating methods (e.g., Array.filter()) to safely manipulate this cached data.
**Action:** When working with Nuxt APIs, always import static JSON files using ES module syntax instead of fs.readFile. When doing so, ensure that data filtering and processing use non-mutating array methods to preserve the integrity of the cached object.
