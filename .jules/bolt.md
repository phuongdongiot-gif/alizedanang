## 2024-06-20 - Nuxt Nitro Bundler Pathing and Memory Caching
**Learning:** In Nuxt/Nitro server deployments, utilizing direct static JSON imports is vastly superior to dynamic `fs.readFile` coupled with `process.cwd()`. Not only does it prevent reading from disk and parsing the JSON string on every request by caching it in memory, but it also natively prevents common serverless production bugs where `process.cwd()` doesn't map to the expected root directory inside bundled edge functions. A critical detail is that the cached module acts as a shared state; any direct mutations persist across requests.
**Action:** When working on backend data fetches in Nuxt, always favor direct imports (`import data from './data.json'`) over runtime `fs` operations for static data. Ensure non-mutating methods (like `.filter()`, `.map()`) are strictly used to safeguard the shared memory cache.
