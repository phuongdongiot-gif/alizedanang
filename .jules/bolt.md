## 2024-05-24 - Optimize JSON Loading in Nuxt Nitro
**Learning:** Nuxt's Nitro server natively supports ES module imports of JSON files. This approach is highly bundler-friendly, automatically caching the parsed object in memory and preventing the overhead of dynamic `fs.readFile` and `JSON.parse` operations at runtime. Additionally, it avoids common production path resolution bugs where `process.cwd()` doesn't reliably map to the source directory. Note: Since the imported JSON object is cached in memory, any mutations made to it will persist across requests; therefore, operations like filtering must use non-mutating methods.
**Action:** When loading static data from JSON files in Nuxt API routes, use direct ES module imports (`import data from '../data.json'`) instead of `fs.readFile`. Always ensure data manipulations are non-mutating.
