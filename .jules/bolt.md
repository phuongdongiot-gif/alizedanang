## 2024-05-16 - Nuxt Nitro Static JSON Imports
**Learning:** In Nuxt/Nitro deployments, using dynamic `fs.readFile` with `process.cwd()` for static JSON files is both inefficient (no in-memory caching) and bundler-unfriendly (can cause bugs in production where `process.cwd()` doesn't point to original source directories). Direct ES module imports of JSON files are automatically bundled and cached in memory. Also, the imported data is read-only, so for reassignments (like filtering) it must be assigned to a mutable variable first (e.g. `let items = faqsData`).
**Action:** Always use direct ES module imports (`import data from '../data.json'`) instead of `fs.readFile` in Nuxt/Nitro for static JSON files to improve performance and production reliability. Ensure variable names match downstream usages and use non-mutating array methods when operating on the cached data.
