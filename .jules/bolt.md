## 2024-05-20 - Nitro JSON Imports vs fs.readFile
**Learning:** In Nuxt/Nitro, using `fs.readFile` with `process.cwd()` to load static JSON data on every request is inefficient and can cause production bugs because `process.cwd()` may not point to the original source directories. Nitro natively supports direct ES module imports of JSON files without import assertions, which automatically bundles and caches the data in memory.
**Action:** Always use direct ES module imports (e.g., `import data from '../data.json'`) instead of `fs.readFile` for static JSON files in Nuxt/Nitro APIs to optimize performance and prevent bundler path issues. When reassigning or filtering imported data, assign the import to a new mutable variable and use non-mutating methods like `Array.filter()` to avoid altering the cached object.
